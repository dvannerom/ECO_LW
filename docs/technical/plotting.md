# Plotting guide

Plotting scripts are under [`plotting/`](../../plotting/). Unless a figure is
an explicit Snakemake output, invoke its script directly; plotting saved
products does not rerun the upstream processing workflow.

## Product maps

These plotters read generated NetCDF products:

```bash
python plotting/plot_narrowband_flux.py \
    --input data/abi_proxy/products/narrowband_flux/narrowband_flux_271_res2km_C0.nc

python plotting/plot_broadband_flux.py \
    --input data/abi_proxy/products/broadband_flux/broadband_flux_271_res2km.nc

python plotting/plot_monthly_flux.py \
    --input data/abi_proxy/products/monthly_flux/monthly_flux_res2km.nc
```

Use input paths that match the products generated by the current configuration.
Map rendering samples every fourth grid cell to limit plotting work and memory;
the source NetCDF remains unchanged. Narrowband spectral irradiance is not
channel-integrated flux. See the [README](../../README.md#main-outputs) for
product units, default output folders, and additional usage notes.

## Finding arguments and outputs

Plotter arguments and defaults are maintained in each script. Run
`python plotting/<script>.py --help` for its current interface rather than
copying command examples from old reports. Many diagnostics require generated
models, metrics, or report files; produce those inputs through Snakemake first.
The current figure-directory conventions are documented in the
[README](../../README.md#main-outputs).

Request both nominal simulation-product figures with:

```bash
snakemake -s workflow/Snakefile --configfile config.yaml --cores 2 nominal_flux_figures
```

They live under `figures/nominal_production/products/{narrowband_flux,broadband_flux}/`.
Plotting numerical budgets no longer exports their CSVs; the corresponding
reporting rules generate tables independently.

The optional `abi_sunny_spectral_comparison` target likewise exports its population
CSV/JSON under `data/nominal_production/diagnostics/abi_sunny/comparison/` before
plotting them. Its plotter now takes the saved consistency CSV as `--input` and
the population JSON as `--summary`; only PNGs go under `figures/`.
